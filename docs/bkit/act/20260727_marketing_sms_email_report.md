# PDCA Report & Act: 마케팅 문자·이메일 기능 점검 및 템플릿 확충 완료

## 1. 개요
마케팅 문자 발송 기능 및 이메일 마케팅 현황을 종합 점검하고, 마케팅에 필수적인 **표준 마케팅 템플릿 5종**과 **템플릿 그룹 5종**을 시드 및 서비스 Fallback으로 구축하였습니다.

---

## 2. 작업 결과 (Accomplishments)

### 2.1 마케팅 템플릿 그룹 5종 및 표준 템플릿 5종 구축
- **그룹**: `프로모션/쿠폰`, `정기배송 혜택`, `크레딧/소멸안내`, `신제품/장비`, `고객케어/안내`
- **템플릿**:
  1. `[프로모션] 이달의 특별 할인 쿠폰 안내` (LMS)
  2. `[정기배송] 소모품 정기배송 특별 혜택 안내` (LMS)
  3. `[크레딧] 보유 크레딧 만료 예정 안내` (LMS)
  4. `[신제품] 신규 팁 출시 및 데모 신청 안내` (LMS)
  5. `[재구매권유] 소모품 정기 점검 및 재주문 안내` (SMS)

### 2.2 `mtsService.ts` Fallback 구현
- DB에 템플릿 데이터가 존재하지 않거나 처음 접속하는 환경에서도 기본 마케팅 템플릿 5종이 UI에 즉시 노출되도록 구현.

### 2.3 `SmsMessageSendPage.tsx` 치환자 간편 도구 칩 확장
- 치환자 태그 `{고객명}`, `{병원명}`, `{크레딧잔액}`, `{만료일}` 치환 태그 칩 추가.
- 실시간 미니 미리보기에서 해당 치환자가 예시 텍스트로 치환되도록 매핑 적용.

### 2.4 DB 마이그레이션 SQL 생성
- `docs/db/sql/20260727_sms_marketing_templates.sql` 파일 생성 완료.
