# PDCA Plan: 스마트 수신대상 세그먼트 타깃팅 기능 구축 (A안 + B안)

## 1. 목적 (Goal)
마케팅 문자 발송시 수신 대상을 정교하게 타깃팅할 수 있도록 **[A안: 맞춤 세그먼트 조건 필터]**와 **[B안: 1-Click 원클릭 스마트 프리셋]**을 모듈화하여 `SmsMessageSendPage.tsx` 및 서비스 레이어에 추가합니다.

---

## 2. 상세 세그먼트 조건 및 구성

### [A안: 맞춤 세그먼트 조건 필터]
- **매출액 (누적 주문금액)**: `최소 N원 이상` ~ `최대 N원 이하`
- **회원 그룹/등급**: `전체`, `VIP`, `골드`, `일반`
- **보유 장비 모델**: `전체`, `Density`, `POTENZA`, `LinearZ`
- **구매 이력/미주문 기간**: `전체`, `30일 이상 미주문`, `60일 이상 미주문`, `90일 이상 미주문`
- **크레딧 상태**: `30일 이내 소멸 임박 크레딧 보유 고객만 포함`

### [B안: 1-Click 원클릭 스마트 추천 프리셋]
1. 💎 **VIP 고객군**: 누적 매출액 1,000만원 이상
2. ⚠️ **이탈 위험군**: 최근 90일 이상 주문이 없는 고객
3. 🔔 **크레딧 소멸 임박**: 30일 이내 만료 예정 크레딧 보유 고객
4. 📦 **정기배송 미이용 고객**: 누적 매출 500만원 이상 중 정기배송 미이용
5. ⚡ **Density 장비 보유군**: Density 장비를 보유한 전용 타깃

---

## 3. 작업 항목 (Tasks)
1. **서비스 확장 (`adminService.ts` 또는 `mtsService.ts`)**:
   - `getFilteredRecipients(filterParams)`: 회원 DB, 주문 집계, 크레딧 상태를 조인/필터링하여 타깃 목록 추출.
2. **UI 구현 (`SmsMessageSendPage.tsx`)**:
   - 수신자 추가 패널에 탭 추가: `[추천 프리셋 (B안)]` | `[맞춤 조건 검색 (A안)]` | `[회원 검색]` | `[엑셀/직접입력]`
   - 추천 프리셋 원클릭 타깃 칩 배치.
   - 맞춤 조건 선택 폼 및 추출 버튼 배치.

---

## 4. 검증 계획 (Verification)
- 프리셋 클릭 시 해당하는 타깃 수신자가 수신 리스트에 바르게 추가되는지 확인.
- 맞춤 조건(예: 매출액 500만원 이상 + 이탈 90일) 설정 후 추출 시 결과 인원수 및 회원 정보가 잘 들어오는지 검증.
- `npm run build` 테스트.
